# Swethaa K — Data Analyst Portfolio

Responsive dark navy and teal portfolio website.

## Run locally
1. Extract the ZIP.
2. Open the `Swethaa Portfolio` folder.
3. Double-click `index.html`, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Included
- `index.html`, `styles.css`, `script.js` — main portfolio website
- `resume/Swethaa_K_Data_Analyst_Resume.pdf` — latest resume PDF supplied by Swethaa
- `dashboards/index.html` — dashboard launch page
- `global_supply_chain_separate_dashboards/01_Executive_Overview.html`
- `global_supply_chain_separate_dashboards/02_Product_Profitability.html`
- `global_supply_chain_separate_dashboards/03_Shipping_Operations.html`
- `assets/` — portfolio visuals

## Resume links
The View and Download Resume actions use the relative path `resume/Swethaa_K_Data_Analyst_Resume.pdf`.

## GitHub Pages
Upload the extracted folder contents to a GitHub repository, then select the deployment branch and root folder under Settings → Pages. Keep all folders in their existing relative locations.
